# Compatibility

| Module Version | Core Version | Status |
|----------------|-------------|--------|
| v0.1.0         | v0.5.8+     | Current |

## Capabilities

- `ai.subtitles`
- `settings`

## Contracts

- Consumes `media.subtitles.search.failed` from `contracts-media` (published by `media-subtitles`)
- Publishes `ai.subtitle.*` from `contracts-ai`

Does not replace `media-subtitles`.
